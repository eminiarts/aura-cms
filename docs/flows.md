# Flows

Aura Base does not include a flow engine, flow resources, or a flow builder. It provides hooks and events that application code can use to react to resource lifecycle changes and customize the admin UI.

For automation that belongs in a reusable package, create a plugin. Plugins can register resources, fields, routes, views, Livewire components, and other application code.
